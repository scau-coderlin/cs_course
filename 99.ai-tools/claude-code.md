```sh
mkdir my-todo

```

```sh
# 给我做一个代办软件，使用HTML实现

# 选择第二项完全授权（可以使用tab+shift来切换）
#    ? for shortcuts: 默认模式，创建和修改文件之前每次都询问用户（最稳妥）
#    accept edits on (shift+tab to cycle): 自动模式，会自动创建或修改文件，不询问用户（最方便）
#    plan mode on (shift+tab to cycle): 规划模式，只讨论，不修改文件，适合构思

# 在ClaudeCode中执行终端命令打开
#    输出 ! ,会处于bash模式, 可以运行任意终端命令
```
